# Correctness — golden vectors for the indicator math

> Generated by `tests/golden/generate.py` — do not edit by hand.
> The gate is `tests/golden-indicators.test.mjs`, which runs every exported
> kernel against `tests/golden/fixtures.json` in CI and fails over
> tolerance. Regenerate only when a convention deliberately changes;
> the committed fixtures are the contract.

## Method

Three layers, in decreasing order of trust:

1. **Independent references** — numpy/pandas implementations in
   `tests/golden/generate.py`, vectorized and algebraically different from
   the JS kernels where possible (rolling-window means against running
   sums, sliding-window mean deviations against per-bar loops,
   convolution against weighted recursion). They encode the conventions
   documented in each kernel's JSDoc — those conventions are the spec.
2. **Third-party cross-check** — the [`ta`](https://pypi.org/project/ta/)
   package (independent authors, TA-Lib-style conventions), where its
   definitions align. Where warm-up seeding differs (`ta` starts the
   recursion at the first value; WickChart seeds with an SMA — the
   TA-Lib convention) the deviation decays geometrically and is measured
   on the last 50 points, reported below.
3. **Hand-derived vectors** — the `tiny10` cases are round-number bars a
   human can verify with a calculator.

Fixtures generated 2026-10-01. Inputs:
`walk150` (150 synthetic bars over 3 midnight-crossing UTC sessions,
deterministic seed), `tiny10`, and `macdline150` (leading-nulls input).

measured on the last 50 points and expected to be small but non-zero.

EMA-sparse, VWAP-session-anchored, population-stdev-as-such, Keltner)
carry no row: layer 1 + layer 3 are their cover.

## Conventions pinned by the fixtures

| kernel | warm-up / convention |
|---|---|
| `calcSMA` / `calcWMA` / `calcStdDev` | first output at index p−1 |
| `calcRealizedVol` | population stdev of log returns; a window needs exactly p finite returns; first output at index p |
| `calcEMA` / `calcEMASparse` | k = 2/(p+1); seed = SMA of the first p values |
| `calcRSI` | Wilder; seed = simple mean of the first p changes; first output at index p |
| `calcATR` | Wilder RMA over true range; seed = SMA of the first p TRs; first bar TR = h−l |
| `calcMACD` | line from index slow−1; signal seeded on the first 9 line values |
| `calcBollinger` | population stdev (ddof=0) |
| `calcVWAP` | hlc3 typical price; cumulative within UTC day; resets at midnight |
| `calcOBV` | first value 0; zero delta adds nothing |
| `calcStoch` | slow stochastic: %K = SMA(smooth) of raw, %D = SMA(smooth) of %K |
| `calcCCI` | mean deviation per window vs the window SMA; 0.015 constant |
| `calcWilliamsR` | (hh − close) / span × −100 |
| `calcDonchian` | rolling hh/ll windows + mid |
| `calcKeltner` | EMA(p) mid ± mult × ATR(p) |
| `calcSuperTrend` | ratcheting ATR bands (reset on tighten or prev-close break); null gap at flips |
| `calcIchimoku` | senkou spans displaced +disp (arrays run past the last bar); chikou displaced back |
| `calcHeikinAshi` | ha-close = ohlc/4; ha-open first = (o+c)/2, then (prev ha-open + prev ha-close)/2 |

## Regenerating

```sh
python tests/golden/generate.py   # rewrites fixtures.json + this file
```

Requires Python 3 with numpy and pandas; `pip install ta` optionally
enables the cross-check layer. The differential test tolerance
(see `tests/golden-indicators.test.mjs`) absorbs the fixtures' 12-
significant-digit rounding.
